MARIO MAKER 2 / TRACK CONDUCTOR

音とレールで、メロディを届ける。

ピアノロール → 読み込み補正 → ぜんまいメソッド → できるだけ短い集音レール

基本設定

読み込み設定

横スクロールでは、音符の列差 × この値を読み込み遅延として反映します。開始画面では0fです。

配置探索

基本は1音符＝1列。共用できる音符は同じ列にまとめ、配線できなければ前後へ少しずつ動かします。

メロディ入力

セルをタップして音符を置きます。同じ時刻に置ける音符は1つです。

4分音符 = 20.000f
音符数 0 演奏時間 0f

音符一覧

計算前の入力内容を確認できます。

#音名開始[f]元の列高さ[b]

配線結果

まだ計算していません。

集音レール概要

計算すると配置が表示されます。
data.js の既存の配線データを利用し、ぜんまいメソッドの探索部分を新しい配置最適化へ接続しています。
